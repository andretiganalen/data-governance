Panduan Uji Manual: Unduh Excel

Len Data Governance · tombol "Unduh Excel" di Settings · disusun 12 Nov 2026

Alamat: http://192.168.125.14:8585 (atau http://dev-data.len.co.id bila DNS aktif). Pakai jendela biasa dan satu jendela Incognito untuk akun kedua. Beri tanda untuk setiap langkah yang lulus.

A. Persiapan akun uji

Atur keanggotaan di Settings → Members → Teams. Dibutuhkan tiga akun (opsional satu lagi).

AkunAtur sebagaiHasil yang diharapkan
Admin (akun Anda)Super Admin atau tim UV-1Berkas berisi semua data
FungsiAnggota satu tim FN_*, mis. FN_Manajemen_RisikoBerkas hanya berisi data Fungsi itu
Lihat sajaHanya tim OrganizationDitolak
Pengunduh (opsional)Hanya tim PengunduhBerkas kosong (header saja)

B. Uji tombol (login sebagai Admin)

  1. Buka Settings (ikon roda gigi).
  2. Cari kartu Unduh Excel di samping Tempat Sampah: ikon dokumen berpanah ke bawah, abu-abu; teks "Hasil Data Governance lengkap dengan atributnya, sesuai hak akses Anda."; ukuran dan bentuk sama dengan kartu di sebelahnya.
  3. Klik kartu: teks menjadi "Menyiapkan berkas…", lalu berkas YYMMDD Data Governance.xlsx terunduh, teks menjadi "Berkas diunduh. Sel merah = wajib diisi, kuning = belum lengkap.", dan kembali normal setelah 6 detik.
  4. Klik dua kali cepat: klik kedua diabaikan, hanya satu berkas terunduh.
  5. Ganti bahasa ke English lalu buka Settings lagi: seluruh teks kartu berbahasa Inggris penuh, tanpa campuran.

E. Cek log di server

cd /home/ubuntu/data-governance/deploy/lendatagovernance
docker compose logs --tail 20 ldg-export

Tiap unduhan tercatat satu baris: nama akun, tingkat, cakupan, jumlah baris. Tidak boleh ada token atau isi data.

F. Jika ada masalah

"Sesi berakhir"Login ulang. Token dibaca dari cookie dg_token yang diisi leno-menu.js

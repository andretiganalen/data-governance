Yang sudah bisa dan belum bisa dilakukan Staf

Sudah bisa

  • Melengkapi definisi istilah dan deskripsi kolom
  • Menetapkan unit pemilik, steward, dan pengguna
  • Memberi label sensitivitas (Restricted, Confidential) dan PII
  • Memperbaiki alur data dari tabel ke layar
  • Menulis aturan mutu per kolom
  • Memberi Tier dan sertifikasi
  • Menanggapi permintaan pengguna dan mencatat keputusan
  • Melihat data siap pakai dan membuat grafik di menu Visualisasi
  • Membuat tabel kerja sendiri di schema workspace
  • Menghapus ke Tempat Sampah dan memulihkan dalam 20 hari
  • Mengelola Glosarium Fungsi Generik dan Master Organisasi; PDF revisi diterbitkan dengan satu tombol, lengkap dengan riwayat revisi
  • Mengunduh hasil Data Governance dalam Excel (sel merah dan kuning menandai isian yang kurang)

Belum bisa

  • Menjalankan pemeriksaan mutu dan melihat hasilnya
  • Menampilkan kesegaran data (waktu pembaruan terakhir)
  • Membuat kontrak data
  • Membentuk produk data dan kontrak data per Fungsi (istilah “domain” di aplikasi ditampilkan sebagai Fungsi)
  • Menampilkan data SDM dan keuangan (sumbernya belum dimuat)
  • Menautkan dokumen kebijakan dan standar ke aset
  • Membatasi unduh data per Tier dan memetakan akun ke unit (disetujui, menunggu data pemetaan)

Setiap prosedur ditulis dari sudut pandang pengguna: apa yang mereka tanyakan, dan apa yang Staf kerjakan supaya jawabannya tersedia di katalog.

4Data siap pakai untuk dashboard

Data siap pakai (lapisan Gold) adalah data yang sudah dibersihkan, diberi nama kolom yang konsisten, dan bisa langsung dipakai untuk dashboard. Semua data ini tersimpan di lakehouse data perusahaan dan dibuka lewat menu Visualisasi di aplikasi. Data diperbarui otomatis setiap kali berkas sumber dimuat ulang.

Cara membuka data siap pakai

  1. Masuk ke aplikasi Len Data Governance seperti biasa, lalu klik menu Visualisasi di sisi kiri. Tidak perlu kata sandi lain.
  2. Pilih tab Risiko ERM atau Tata Kelola Data untuk dashboard yang sudah jadi, atau Semua dashboard untuk daftar lengkap.
  3. Untuk grafik baru, buka tab Grafik, pilih dataset Gold (nama diawali gold_), lalu pilih jenis grafik.
  4. Untuk kueri sendiri, buka tab SQL Lab. Semua tabel resmi hanya bisa dibaca. Simpan hasil olahan Anda sebagai tabel di schema workspace, dengan menulis nama lengkapnya, misalnya CREATE TABLE workspace.risiko_unit_saya AS SELECT …. Berkas CSV/XLSX pribadi juga bisa diunggah, hanya ke workspace.

5Menjawab pengguna: pesan standar

Gunakan pesan ini di Activity Feeds & Tasks saat jawaban belum tersedia. Sampaikan saja statusnya (Belum ada atau Belum bisa) tanpa uraian teknis.

Kontrak data — "Kontrak data untuk tabel ini belum ada. Kebutuhan Anda kami catat dan teruskan ke pemilik data, @unit pemilik."
Hasil uji dan kesegaran — "Aturan mutu tabel ini sudah tercatat di tab Data Observability. Hasil pemeriksaannya belum bisa ditampilkan. Untuk keputusan penting, mohon konfirmasi ke @unit pemilik."
Definisi kosong — "Definisi istilah ini belum ada. Kami lengkapi bersama @unit pemilik paling lambat tanggal."
Data siap pakai — "Data untuk dashboard tersedia di menu Visualisasi, tab Risiko ERM atau Tata Kelola Data. Masuk dengan akun Anda yang sama, tanpa kata sandi lain."
Isi data — "Halaman katalog memuat keterangan data. Angka siap pakai bisa dilihat di menu Visualisasi. Isi transaksi rinci dibuka di aplikasi asal sesuai hak akses unit Anda."
